# 性能优化规则
      performance:
        - "所有StatelessWidget必须使用const构造函数"
        - "优先使用const值而不是运行时计算"
        - "ListView必须使用.builder构造函数 + itemExtent"
        - "避免在build方法中创建新对象"
        
      # 代码结构规则  
      architecture:
        - "每个dart文件不超过300行"
        - "使用单一职责原则，每个类只负责一个功能"
        - "组合优于继承，使用小部件组合"
        - "状态管理使用Riverpod，provider命名规范：*Provider"
        
      # UI/UX规范
      ui_ux:
        - "使用响应式设计，800px为断点"
        - "颜色和尺寸必须从app_theme.dart引用"
        - "添加适当的动画和微交互"
        - "文本显示必须有层次对比（标题/正文/辅助文字）"
        
      # 内存管理规则
      memory_management:
        - "实时文本必须分块管理，避免单个字符串过长"
        - "长列表必须使用ListView.builder"
        - "定期清理不再需要的资源"
        - "添加内存使用监控和日志"
        
      # 错误处理规则
      error_handling:
        - "所有异步操作必须有try-catch"
        - "用户操作必须提供反馈（成功/失败）"
        - "录音权限被拒绝时提供引导"
        
      # 特定组件规范
      components:
        - "录音按钮：必须有视觉状态反馈（录制中/暂停/停止）"
        - "文本显示：自动在句号后换行，支持平滑滚动"
        - "时间线：左侧连接线必须对齐，有时间间隔视觉提示"
        
      # 开发提示
      hints:
        - "考虑低配设备性能，在可能的地方添加降级方案"
        - "为重要操作添加震动反馈"
        - "使用适当的emoji增强可读性"
        - "保持代码可测试性，业务逻辑与UI分离"
